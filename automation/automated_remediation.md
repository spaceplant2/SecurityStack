# Automation Platforms

N8N is a an enterprise-class automation platform that can be adapted to provide automated remediations in a security environment. Some of the integrations are pre-built and some may need to be custom developed but the platform is flexible enough that this should not be difficult.

Shuffle is a security-specific automation platform that is noteable for its focus on working with the services that we are focusing on in our security stack. The fact that this platform comes with pre-build integrations makes this a preferred choice for many security engineers.
