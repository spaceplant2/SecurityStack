# Configuration Automation

__Ansible:__ *A tool for ensuring configurations while also observing the principle of idempotebility*

Ansible is a tool to manage configurations in an environment with a large collection of official integrations and an even larger collection of community developed integrations. Most devices running on modern operating systems can be managed with Ansible and there are other platforms that can integrate so to make tracking configurations and changes easier.

Some of the GUI integrations that exist are Tower, Semaphore-UI, Rundeck, and Netbox. These all provide structure around Ansible playbooks, or you can stay with the CLI that still allows an enormous ammount of flexibility.
